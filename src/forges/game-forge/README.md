# GameForge

Status: stub. The GameForge implementation is out of scope for this change. This directory only defines the integration schema and asset registry shape.

## Integration points

- WorldForge: supplies world geography and constraints.
- MechanicsForge: supplies rule sets and simulation mechanics.
- ModelForge: supplies model assets referenced by game content.
- GameDesignForge: supplies design documents and content specs.

The full schema is in [schema.yml](schema.yml). For how GameForge fits with the other forges, see [ECOSYSTEM](../ECOSYSTEM.md).
